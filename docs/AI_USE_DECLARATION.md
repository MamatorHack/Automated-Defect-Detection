# Generative AI Use Declaration

This project follows the course regime **Permitted with Declaration**.

## Material use

Generative AI tools were used to support:

- software architecture planning;
- code generation and refactoring;
- test design;
- documentation structure and wording;
- risk analysis;
- preparation of the demonstration and technical report.

## Human verification

The team remains responsible for every submitted component. Generated code must be executed and reviewed, technical claims must be checked against real sources, and all metrics/results must come from real runs. Human changes include adapting generated code to the repository, verifying interfaces and dependencies, reviewing model assumptions, selecting validation procedures, and correcting any unsupported claim.

## What AI output is not used for

AI output is not treated as an authoritative technical source, and no fabricated metric, test result, citation, dataset property, or execution evidence may be submitted.
