ENGINEERING DECISION

Screw alignment was tested — and not promoted.

Canonical alignment improved Screw ranking metrics (AUROC/AP) but worsened the selected operating point by increasing false negatives. The current verified model therefore remains deployed. This preserves the decision objective instead of optimizing a single headline metric.

PRODUCTION BOUNDARY

Industrialized prototype ≠ certified factory system

This implementation demonstrates the software architecture, traceability, model lifecycle, validation discipline, and human-control workflow. A real factory deployment would still require authentication, TLS, centralized monitoring, camera/PLC/MES integration, formal change control, backup policy, drift monitoring, security hardening, and acceptance criteria validated with the target production line.
